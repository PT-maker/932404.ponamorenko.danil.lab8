## База данных

**reservations**

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER, PRIMARY KEY | идентификатор брони |
| name | TEXT, NOT NULL | имя гостя |
| party_size | INTEGER, NOT NULL | количество гостей, `CHECK (party_size BETWEEN 1 AND 20)` |
| date_time | TEXT, NOT NULL | дата и время в формате `ГГГГ-ММ-ДДTЧЧ:ММ` |
| status | TEXT, NOT NULL | `pending`, `confirmed` или `cancelled` |

Занятость зала на выбранное время считается запросом:

```sql
SELECT COALESCE(SUM(party_size), 0) FROM reservations
WHERE status != 'cancelled'
  AND date_time > ? AND date_time < ?;
```

При первом запуске таблица создаётся автоматически и заполняется тестовыми данными (6 броней). Запросы выполняются с параметрами (`?`), что защищает от SQL-инъекций.

## Маршруты

| Метод | Путь | Описание | Коды ответа |
|-------|------|----------|-------------|
| GET | `/api/reservations` | список броней по времени | 200, 400 |
| GET | `/api/reservations?date=2026-12-01` | брони на выбранную дату | 200, 400 |
| GET | `/api/reservations?status=confirmed` | брони с выбранным статусом | 200, 400 |
| GET | `/api/reservations/{id}` | одна бронь | 200, 404 |
| POST | `/api/reservations` | создать бронь | 201, 400, 409 |
| PUT | `/api/reservations/{id}` | обновить бронь | 200, 400, 404, 409 |
| DELETE | `/api/reservations/{id}` | удалить бронь | 204, 404 |
| GET | `/api/availability?date_time=2026-12-01T19:00` | занятость зала на указанное время | 200, 400 |

### Пример создания

```
POST /api/reservations
```
```json
{
  "name": "Новиков Игорь",
  "party_size": 4,
  "date_time": "2026-12-01T19:00"
}
```

Ответ `201`:

```json
{
  "id": 7,
  "name": "Новиков Игорь",
  "party_size": 4,
  "date_time": "2026-12-01T19:00",
  "status": "pending"
}
```

### Пример занятости зала

```
GET /api/availability?date_time=2026-12-01T19:00
```

Ответ `200`:

```json
{
  "capacity": 40,
  "occupied": 12,
  "free": 28,
  "percent": 30
}
```

### Ошибки

Все ошибки возвращаются в формате `{"error": "описание"}`:

| Ситуация | Код |
|----------|-----|
| пустое `name` | 400 |
| `party_size` вне диапазона 1–20 | 400 |
| `date_time` в неверном формате | 400 |
| бронирование на прошедшее время | 400 |
| неверный тип или отсутствующее обязательное поле | 400 |
| бронь с таким `id` не найдена (GET, PUT, DELETE) | 404 |
| недостаточно свободных мест | 409 |

Пример ответа при нехватке мест:

```json
{ "error": "Недостаточно мест: свободно 6 из 40" }
```
